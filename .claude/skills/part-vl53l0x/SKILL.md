# VL53L0X time-of-flight laser distance sensor (VL53L0X)

## Overview
The **VL53L0X** from STMicroelectronics is a FlightSense time-of-flight ranging sensor. It sends out 940 nm infrared laser pulses (Class 1, eye-safe) and times how long the reflections take to come back. This gives an absolute distance in millimetres, and the result does not depend on the target's colour or reflectance.
- Typical range: up to about 1.2 m in default mode and about 2 m in long-range mode, depending on lighting and the target.
- Each measurement takes about 30 ms with the default timing budget.
- Hobbyists usually buy it on the **GY-530 / GY-VL53L0XV2** breakout (Pololu and Adafruit make similar boards). These boards have a 2.8 V LDO, I2C level shifting and pull-ups.

## Electrical limits
- Bare chip AVDD: 2.6–3.5 V (datasheet). Breakout VIN: about 2.6–5 V through the on-board regulator.
- Current: about 19 mA on average while ranging and about 5 µA in hardware standby (XSHUT low). Peak current is higher, so add a 10 µF bulk capacitor.
- I2C: up to 400 kHz.
- Operating temperature: −20 to +70 °C.

## Interface details
- **I2C address: 0x29** (7-bit; the datasheet gives 0x52 as the 8-bit write address). You can change it in software through register **0x8A**, but the change is lost at power-down.
- Identification registers: **0xC0 = 0xEE** (model ID), 0xC1 = 0xAA, 0xC2 = 0x10.
- ST does **not** publish a full register map. The official driver is the C "VL53L0X API" (STSW-IMG005). The driver here follows the open-source Pololu port of that API. Registers it uses:
  - 0x00 SYSRANGE_START: 0x01 = single shot, 0x02 = continuous.
  - 0x13 RESULT_INTERRUPT_STATUS: bits 2:0 are non-zero when data is ready.
  - 0x1E (RESULT_RANGE_STATUS + 10): 16-bit big-endian range in mm.
  - 0x0B SYSTEM_INTERRUPT_CLEAR: write 0x01 after reading.
  - 0x44: signal rate limit, 16-bit value in Q9.7 format (default 0.25 MCPS).
- Out-of-range readings return **8190 or 8191**.

## Using the driver
```python
from machine import I2C, Pin
import time
from vl53l0x import VL53L0X

i2c = I2C(0, sda=Pin(4), scl=Pin(5), freq=400000)   # Pico
tof = VL53L0X(i2c)
while True:
    mm = tof.read()
    print('out of range' if mm >= 8190 else '%d mm' % mm)
    time.sleep_ms(100)
```
For faster streaming, call `tof.start_continuous()` once and then call `tof.read_continuous()` in a loop.

**Several sensors on one bus:**
1. Hold all XSHUT pins low.
2. Release one sensor, create a `VL53L0X(i2c)` object for it and call `set_address(0x30)`.
3. Release the next sensor and give it a different address. Repeat for the rest.

## Gotchas
- **Remove the protective film** from the sensor window before use.
- The address resets to 0x29 on every power cycle or XSHUT reset.
- This simplified driver keeps the default timing budget (about 33 ms) and does not do offset or crosstalk calibration. Expect accuracy of a few percent, with the worst results on very close targets (under 3 cm) or very dark ones.
- Strong sunlight or infrared light shortens the range a lot.
- The field of view is about 25°, so a wide cone may "see" the table or nearby walls.
- If you use the bare chip without a regulator, never give it more than 3.5 V.
- `io_2v8=True` sets the chip's I/O to 2.8 V mode, which matches typical breakouts. Use False only if you drive the bare chip's I/O at 1.8 V.
