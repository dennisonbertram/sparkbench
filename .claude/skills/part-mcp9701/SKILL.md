# MCP9701 analog temperature sensor (MCP9701-E/TO)

## Overview
The **MCP9701** (Microchip, "Linear Active Thermistor IC") is a low-power temperature sensor with a linear voltage output. It has no digital interface: you read the output with an ADC. Hobbyists buy the **MCP9701-E/TO** (or the more accurate **MCP9701A-E/TO**) in a 3-pin TO-92 package.
- Temperature coefficient: **19.5 mV/°C** with **400 mV at 0 °C**
- Output: **205 mV at −10 °C**, **887.5 mV at 25 °C**, **2.84 V at 125 °C**
- Specified **−10 °C to +125 °C**
- Accuracy: MCP9701 ±2 °C typ (−4/+4 °C max, 0–70 °C); MCP9701A ±1 °C typ (±2 °C max, 0–70 °C)
- Supply: **3.1 V to 5.5 V**, only **6 µA** typical (12 µA max)

## Pinout (TO-92, flat face towards you, legs down)
| Pin | Name | Function |
|-----|------|----------|
| 1 (left) | VDD | Supply, 3.1–5.5 V |
| 2 (middle) | VOUT | Analog output, 400 mV + 19.5 mV/°C |
| 3 (right) | GND | Ground |

Datasheet "Package Types" (page 2) and Table 3-1: TO-92 pin 1 VDD, pin 2 VOUT, pin 3 GND.

## Electrical limits
- Supply: 3.1 V min, 5.5 V max (absolute max 6.0 V). 3.3 V works, but only 0.2 V above the minimum.
- Output: 100 µA source/sink max (absolute max ±30 mA). VOUT stays between about 0.2 V and 2.84 V, so it is safe for a 3.3 V ADC even with a 5 V supply.
- Designed to drive large capacitive loads (tested with 1000 pF).

## Interface details
Conversion formula (datasheet Equation 4-1, VOUT = TC × TA + V0°C):
```
T(°C) = (Vout(mV) − 400) / 19.5
```
Examples: 0.400 V = 0 °C, 0.8875 V = 25 °C, 1.180 V = 40 °C, 2.35 V = 100 °C.
Put a 0.1 µF to 1 µF ceramic capacitor between VDD and GND close to the sensor (datasheet section 4.3). In noisy setups feed VDD through a 200 Ω resistor with a 1 µF capacitor.

## Wiring
| Sensor | ESP32 | Raspberry Pi Pico | Raspberry Pi 4 |
|---|---|---|---|
| VDD | 3V3 | 3V3(OUT) (pin 36) | 3.3 V (pin 1) |
| VOUT | GPIO34 (ADC1) | GP26 / ADC0 (pin 31) | External ADC input (e.g. MCP3008 CH0 or ADS1115 A0) |
| GND | GND | GND | GND |

The Raspberry Pi 4 has **no built-in ADC**, so you need an external ADC. On the ESP32 use ADC1 pins (ADC2 does not work while Wi-Fi is on).

## Using the driver
```python
from mcp9701 import MCP9701
import time
sensor = MCP9701(26)        # GPIO number of the ADC pin VOUT is wired to
while True:
    print('T=%.1fC' % sensor.temperature())
    time.sleep(1)
```
The driver averages 32 samples. It uses calibrated `read_uv()` where the port has it (ESP32), otherwise `read_u16()` × 3.3 V / 65535 (pass `vref=` if your 3V3 rail is different).

## Gotchas
- **Pin orientation:** reversing VDD and GND can destroy the sensor. If it gets warm, unplug it.
- **Look-alikes:** the MCP9700 uses 10 mV/°C and 500 mV at 0 °C; the LM35 has no offset; the TMP36 uses 10 mV/°C and 500 mV. Check the marking on the package before using this formula.
- **Supply minimum is 3.1 V:** unlike the MCP9700 (2.3 V), it will not work from a 3.0 V coin cell or a sagging rail.
- **ESP32 above ~2.5 V:** the ESP32 ADC is less accurate near the top of its 11 dB range, so readings above roughly 100 °C (2.35 V) get less reliable.
- **Accuracy:** the plain MCP9701 is only ±2 °C typical (up to +6 °C off at 125 °C). A one-point calibration at room temperature improves it to about ±0.5 °C from 0 to 70 °C.
- **Placement:** the die sees the temperature of its legs and the PCB more than the air. Keep it away from the regulator and MCU.
