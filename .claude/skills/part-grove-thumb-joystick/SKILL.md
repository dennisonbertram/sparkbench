# Grove - Thumb Joystick v1.1 (analog X/Y + click)

## Overview
The **Seeed Grove - Thumb Joystick v1.1 (SKU 101020028)** is a PS2-style thumb stick on a Grove board. There is no chip on it:
- Two **10 kΩ potentiometers** (X and Y). Each track has a **4.7 kΩ resistor in series at both ends** (R6/R1 on X, R3/R5 on Y), so the outputs swing only about **0.2 × VCC to 0.78 × VCC**, about 0.5 × VCC at rest.
- The stick's **push switch shorts X directly to VCC**. A click therefore shows up as X reading full scale (Seeed: "only when being pressed the X value will be set to 1023").
- Seeed's specification on a 10-bit ADC: X 206 / 516 / 798, Y 203 / 507 / 797 (min / typ / max counts).

## Pinout (Grove connector, pin 1 to 4)
| Pin | Name | Wire colour | Function |
|-----|------|-------------|----------|
| 1 | X | yellow | X wiper (OUT_X), 0.2-0.78 × VCC; = VCC while clicked |
| 2 | Y | white | Y wiper (OUT_Y), 0.2-0.78 × VCC |
| 3 | VCC | red | Supply, 3.3 V or 5 V |
| 4 | GND | black | Ground |

Source: Seeed schematic Joystick.pdf (J2: 1 OUT_X, 2 OUT_Y, 3 VCC, 4 GND) and the Seeed wiki wire table (yellow = A0, white = A1, red = 5V, black = GND).

## Electrical limits
- Seeed lists 4.75-5.25 V (for a 5 V Seeeduino), but the module is passive and ratiometric. **On an ESP32 or Pico power it from 3.3 V**: a click puts the full VCC on X.
- Current: two 19.4 kΩ dividers, about 0.35 mA at 3.3 V (0.5 mA at 5 V).
- Source resistance at X/Y: about 4.9 kΩ at mid-travel; fine for an MCU ADC.

## Interface details
```
f = V / VCC                        (ratiometric)
X position % = 100 × (f − 206/1023) / ((798 − 206)/1023)
Y position % = 100 × (f − 203/1023) / ((797 − 203)/1023)
clicked      = X f > 900/1023      (normal travel stops at 798/1023)
```
At 3.3 V: X 0.66 V = 0 %, 1.62 V = 50 %, 2.57 V = 100 %, 3.3 V = clicked.
The end points vary a little between units; use `calibrate()` for exact values.

## Wiring
Use a Grove-to-female-jumper cable, or a Grove shield / hat analog port (X on A0, Y on A1).

| Joystick | ESP32 | Raspberry Pi Pico | Raspberry Pi 4 |
|---|---|---|---|
| X (yellow) | GPIO34 (ADC1) | GP26 / ADC0 | External ADC (Grove Base Hat A0, ADS1115) |
| Y (white) | GPIO35 (ADC1) | GP27 / ADC1 | External ADC (Grove Base Hat A1) |
| VCC (red) | 3V3 | 3V3(OUT) | 3.3 V (pin 1) |
| GND (black) | GND | GND | GND |

The Raspberry Pi 4 has no built-in ADC.

## Using the driver
```python
from grove_thumb_joystick import GroveThumbJoystick
import time
js = GroveThumbJoystick(34, 35)       # GPIOs wired to X and Y
while True:
    if js.pressed():
        print('CLICK Y=%d' % round(js.y()))
    else:
        print('X=%d Y=%d' % (round(js.x()), round(js.y())))
    time.sleep(0.5)
```
`x()` / `y()` return 0-100 % of travel (`x()` returns None while clicked), `pressed()` detects the click, `x_volts()`, `y_volts()`, `x_fraction()`, `y_fraction()` give the raw signals, and `calibrate(x_min, x_max, y_min, y_max)` takes your own end points as fractions of VCC. Pass `vcc=` if the module is not on 3.3 V.

## Gotchas
- **No separate button pin:** the click is only visible on X. While the stick is held down you cannot read the X position.
- **Outputs never reach 0 V or VCC** while moving: do not map 0-4095 to the full stick range, or the stick will only cover the middle 60 %.
- **5 V on a 3.3 V board:** a click drives X to VCC; on 5 V that can damage an ESP32/Pico ADC pin.
- **ESP32:** use ADC1 pins (GPIO32-39); ADC2 does not work while Wi-Fi is on. Add a small dead zone around the rest position.
- **Simulator:** Sparkbench models the X and Y positions only; the click pulling X to VCC is not simulated.
