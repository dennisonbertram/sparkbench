# SS49E linear Hall-effect sensor, KY-035 module (SS49E)

## Overview
The **SS49E** (Honeywell SS39ET/SS49E/SS59ET series) is a linear Hall-effect sensor. It gives an **analog voltage proportional to the magnetic field** through its face, for either pole. Hobbyists buy it on the **KY-035 "analog Hall magnetic sensor" module** (37-in-1 kits, Joy-IT SensorKit). The module wires the 3-pin flat TO-92 sensor straight to a 3-pin header (−, +, S), with no other parts. Some KY-035 boards carry an equivalent "49E" chip (for example Diodes AH49E) instead of the Honeywell part.
- Null output (0 G): **Vs/2** (2.50 V at 5 V, 2.25–2.75 V between parts)
- Sensitivity: **1.4 mV/G typ** (1.0–1.75) at Vs = 5 V, about 0.28 mV/G per volt of supply
- Range: **±650 G min, ±1000 G typ** (1 mT = 10 G)
- Supply: 2.7–6.5 V (chip); the module is sold for 3.3–5 V. About 6 mA at 5 V
- Response time 3 µs; linearity −0.7 % of span

## Pinout (KY-035, header order)
| Pin | Name | Function |
|-----|------|----------|
| 1 | − | Ground |
| 2 | + | Supply, 3.3–5 V (middle pin, often unlabeled) |
| 3 | S | Analog output: Vs/2 with no field, ± about 0.92 mV/G at 3.3 V |

## Electrical limits
- Supply: 2.7–6.5 V operating, −5 V to 8 V absolute maximum.
- Output: sources up to 1.0 mA min (Vs > 3 V); absolute maximum 10 mA. Output span about 0.95 V to Vs − 0.95 V.
- Operating temperature −40 °C to 100 °C.

## Interface details
The output is set by the supply voltage (ratiometric):
```
B (gauss) = (Vout − Vs/2) / (0.0014 V/G × Vs / 5 V)
```
At Vs = 3.3 V: 1.65 V = 0 G, sensitivity 0.924 mV/G, so ±1000 G spans 0.73–2.57 V.
At Vs = 5 V: 2.5 V = 0 G, 1.4 mV/G, ±1000 G spans 1.1–3.9 V.
The sign tells you the pole: one pole raises the output, the other lowers it.

## Wiring
| KY-035 | ESP32 | Raspberry Pi Pico | Raspberry Pi 4 |
|---|---|---|---|
| − | GND | GND | GND (pin 6) |
| + | 3V3 | 3V3(OUT) (pin 36) | 3.3 V (pin 1) |
| S | GPIO34 (ADC1) | GP26 / ADC0 (pin 31) | External ADC (e.g. ADS1115 A0) |

Power it from **3.3 V** on a 3.3 V board: with 5 V the output reaches about 3.9 V at +1000 G, past the ADC pin's limit.

## Using the driver
```python
from ss49e import SS49E
import time
hall = SS49E(26)          # GPIO of the ADC pin S is wired to; vcc=3.3 by default
hall.calibrate_zero()     # run with no magnet nearby
while True:
    print('B=%.0fG' % hall.gauss())
    time.sleep(0.5)
```
Pass `vcc=5.0` if you power it from 5 V (and add a divider on S). `millitesla()` returns mT.

## Gotchas
- **Calibrate the null:** the 0 G output varies by ±10 % between parts, worth ±180 G uncorrected. Call `calibrate_zero()` with no magnet nearby.
- **Typical, not exact, sensitivity:** 1.0–1.75 mV/G across parts. For accurate gauss, calibrate against a known magnet; for "how close is the magnet" the typical value is fine.
- **Neodymium magnets saturate it** when close: the output stops at about 0.95 V / Vs − 0.95 V.
- **Only the field through the face counts:** turn the magnet's pole toward the flat marked face of the chip.
- **ESP32 ADC:** use ADC1 pins (GPIO32–39); ADC2 stops working with Wi-Fi on. The Raspberry Pi has no ADC.
- Not a switch: for on/off magnet detection use a latching or switching Hall module (KY-003, KY-024 DO).
