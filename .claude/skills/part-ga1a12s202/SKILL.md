# GA1A12S202 log-scale analog light sensor (Sharp GA1A1S202WP)

## Overview
The **GA1A1S202WP** (Sharp OPIC light detector) combines a photodiode, a current amplifier and a **log amplifier**: it sources an output current proportional to the **logarithm** of illuminance, with a human-eye response (peak 555 nm). Hobbyists buy it as the **Adafruit GA1A12S202 Log-scale Analog Light Sensor (product ID 1384)**, which adds a **68 kΩ load resistor** from OUT to GND so the current becomes a voltage.
- Output current (Vcc = 2.9 V, illuminant A): **Io = 10 × log10(Ev) µA** — typ 20 µA at 100 lx (16–24), 30 µA at 1000 lx (27–33), ≤ 1 µA in the dark
- On the breakout: **V(OUT) = Io × 68 kΩ = 0.68 V × log10(lux)**, so **lux = 10^(V / 0.68)**
- Dynamic range **3 to 55 000 lx** (≈ 0.32 V to ≈ 3.2 V): it is hard to saturate, works indoors and outdoors
- No calibration needed between boards (the log amp is on-chip); about ±0.25 %/°C

## Electrical limits
- Supply: datasheet recommended 2.3–3.2 V, absolute max −0.3 to +7.0 V. Adafruit rates the board for 2.3–6 V; 3.3 V and 5 V rails both work.
- Output current 1 mA absolute max (the 68 kΩ load keeps it ~50 µA).
- Supply current 70 µA typ, 150 µA max (at 1000 lx), plus the output current.
- Operating temperature −40 to +85 °C.
- OUT stays below about 3.2 V even in full sunlight, so it is safe for a 3.3 V ADC on either supply.

## Interface details
```
Io(µA) = V(OUT) / 68 kΩ × 10^6
log10(Ev) = Io / 10 µA                 (datasheet: Io = 10 × log(Ev) µA)
Ev(lx)  = 10 ^ (V(OUT) / 0.68)
```
Examples: 0.68 V = 10 lx, 1.36 V = 100 lx, 2.04 V = 1000 lx, 2.72 V = 10 000 lx, 3.2 V ≈ 50 000 lx.
Because the response is logarithmic, a fixed ADC error is a fixed **percentage** error in lux: 1 mV ≈ 0.34 %.

## Wiring
| Sensor | ESP32 | Raspberry Pi Pico | Raspberry Pi 4 |
|---|---|---|---|
| VCC | 3V3 | 3V3(OUT) (pin 36) | 3.3 V (pin 1) |
| OUT | GPIO34 (ADC1) | GP26 / ADC0 (pin 31) | External ADC input (e.g. MCP3008 CH0 or ADS1115 A0) |
| GND | GND | GND | GND |

The Raspberry Pi 4 has no built-in ADC. Keep the sensor's leads short or add 0.01 µF across VCC/GND (datasheet note 7-1) if readings are noisy.

## Using the driver
```python
from ga1a12s202 import GA1A12S202
import time
sensor = GA1A12S202(26)        # GPIO number of the ADC pin OUT is wired to
while True:
    print('L=%dlx' % round(sensor.lux(), -1))  # 3 significant figures: the ADC reading jitters by a count
    time.sleep(1)
```
The driver averages 16 samples. It uses calibrated `read_uv()` where the port has it (ESP32), otherwise `read_u16()` × 3.3 V / 65535 (pass `vref=` if your rail differs). `volts()`, `microamps()` and `log_lux()` give the raw quantities; `log_lux()` (decades) is handy for brightness thresholds and dimming curves.

## Gotchas
- **It is logarithmic:** do not scale the voltage linearly to lux. Each 0.68 V step is ×10 in light.
- **Below 3 lx** the output is outside the specified range (dark current ≤ 1 µA ≈ 68 mV); treat readings under ~0.3 V as "dark".
- **ESP32 ADC:** use ADC1 pins (ADC2 does not work while Wi-Fi is on) and 11 dB attenuation; uncalibrated `read()` is non-linear, so prefer `read_uv()`.
- **Light source:** specified with a tungsten lamp (CIE illuminant A); white LEDs / fluorescent read within ±2 µA (about ±0.2 decade worst case).
- **Discontinued at Adafruit** (successors: VEML7700, ALS-PT19), but boards are still in circulation.
