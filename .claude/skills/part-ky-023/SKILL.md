# KY-023 dual-axis analog joystick module

## Overview
The **KY-023** is the common black 5-pin thumb-joystick module (PS2-style stick). It holds no chip: just
**two 10 kΩ potentiometers** at 90° (X and Y) and a **push switch** under the stick.
- Each axis wiper outputs a voltage proportional to its position: **0 V at one end, Vcc at the other, about Vcc/2 at rest**
- The switch connects **SW to GND when the stick is pressed** (active low, no pull-up fitted on most boards)
- Supply: **3.3 V to 5 V** (the silkscreen says +5V). About 0.33 mA per pot at 3.3 V (0.5 mA at 5 V)

## Pinout (5-pin header, as printed on the board)
| Pin | Name | Function |
|-----|------|----------|
| 1 | GND | Ground |
| 2 | +5V | Supply for both pots, 3.3–5 V (use 3.3 V with a 3.3 V MCU) |
| 3 | VRx | X-axis wiper voltage, 0..Vcc |
| 4 | VRy | Y-axis wiper voltage, 0..Vcc |
| 5 | SW | Push switch to GND (needs a pull-up) |

## Electrical limits
- The outputs swing all the way to the supply. **Powered from 5 V, VRx/VRy reach 5 V, which can damage an ESP32 or Pico ADC pin.** With a 3.3 V MCU always connect +5V to 3V3.
- Pots are 10 kΩ, so the source impedance at the wiper is up to 2.5 kΩ: fine for MCU ADCs.

## Interface details
Ratiometric potentiometer divider:
```
Vout = position × Vcc        position(%) = 100 × Vout / Vcc
```
At rest each axis reads about 50 % (1.65 V on 3.3 V); spring centering is imprecise, so expect a few % offset and use a dead zone.
SW: configure the GPIO as an input with the internal pull-up; it reads 0 while the stick is pressed.

## Wiring
| Module | ESP32 | Raspberry Pi Pico | Raspberry Pi 4 |
|---|---|---|---|
| GND | GND | GND | GND |
| +5V | 3V3 | 3V3(OUT) (pin 36) | 3V3 (pin 1) |
| VRx | GPIO34 (ADC1) | GP26 / ADC0 (pin 31) | External ADC (e.g. MCP3008 CH0) |
| VRy | GPIO35 (ADC1) | GP27 / ADC1 (pin 32) | External ADC (e.g. MCP3008 CH1) |
| SW | GPIO4 (internal pull-up) | GP15 (internal pull-up) | GPIO17 (internal pull-up) |

The Raspberry Pi 4 has **no built-in ADC**. On the ESP32 use ADC1 pins (ADC2 does not work while Wi-Fi is on).

## Using the driver
```python
from ky023 import KY023
import time
js = KY023(34, 35, 4)        # GPIOs wired to VRx, VRy, SW
while True:
    print('X=%d Y=%d SW=%d' % (round(js.x()), round(js.y()), js.pressed()))
    time.sleep(0.2)
```
`x()` / `y()` return 0–100 % of travel; `xy_centered()` returns −100..+100 with a dead zone; `pressed()` is True while the stick is pushed. Pass `vcc=` if the module is not on 3.3 V (it must still not exceed the ADC's input range).

## Gotchas
- **Do not power from 5 V on a 3.3 V board** – the wipers then output up to 5 V.
- **SW floats when released**: without a pull-up it reads random values. Use `Pin.PULL_UP` (or fit the 10 kΩ R1 pad some boards have).
- **Axis direction** depends on how the module is mounted: with the header on the left, X and Y may appear swapped or inverted. Flip in software.
- **ESP32 ADC** is nonlinear near 0 V and saturates near 3.1–3.3 V, so the very ends of travel read a little short; this is normal.
- The centre value differs between modules; calibrate it at start-up if you need exact zero.
