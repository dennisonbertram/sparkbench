# AH3503 linear Hall-effect sensor (AH3503, TO-92)

## Overview
The **AH3503** (Nanjing AH Electronics) is a linear Hall-effect sensor in a 3-pin TO-92 package. Inside are a voltage regulator, a Hall element, a linear amplifier and an emitter-follower output. It gives an **analog voltage proportional to the magnetic field** through its marked face, for either pole. Hobbyists buy the bare chip, sold as "AH3503 linear Hall sensor TO-92".
- Quiescent output (B = 0): **2.5 V typ** (2.25–2.75 V between parts)
- Sensitivity: **13.5 mV/mT typ** (7.5–17.5 mV/mT), i.e. 1.35 mV/G
- Linear range: **±90 mT** (±900 G); flat response to 23 kHz
- Supply: **4.5–6 V**, 9 mA typ (14 mA max)
- Output resistance 50 Ω

## Pinout (TO-92, marked face towards you, legs down)
| Pin | Name | Function |
|-----|------|----------|
| 1 (left) | VCC | Supply, 4.5–6 V |
| 2 (middle) | GND | Ground |
| 3 (right) | OUT | Analog output, 2.5 V ± 13.5 mV/mT |

## Electrical limits
- Supply: 4.5 V min, 6 V max (6 V is also the absolute maximum). **3.3 V is too low:** power it from 5 V.
- Operating temperature −20 °C to +85 °C.
- Output swings about 1.29 V to 3.72 V over ±90 mT, **above 3.3 V** for strong fields of one pole.

## Interface details
```
B (mT) = (Vout − 2.5 V) / 0.0135 V/mT        (1 mT = 10 G)
```
Examples: 2.5 V = 0 mT, 3.04 V = +40 mT, 1.96 V = −40 mT, 3.715 V = +90 mT.
With a 10 kΩ (top) / 20 kΩ (bottom) divider the ADC pin sees 2/3 of Vout (max about 2.48 V); multiply back by 1.5.

## Wiring
| AH3503 | ESP32 | Raspberry Pi Pico | Raspberry Pi 4 |
|---|---|---|---|
| VCC | 5V / VIN | VBUS (pin 40) | 5V (pin 2) |
| GND | GND | GND | GND |
| OUT | 10 kΩ to GPIO34 (ADC1), 20 kΩ GPIO34→GND | 10 kΩ to GP26 / ADC0, 20 kΩ GP26→GND | External ADC (e.g. ADS1115 A0) |

Add a 0.1 µF capacitor across VCC and GND near the sensor.

## Using the driver
```python
from ah3503 import AH3503
import time
hall = AH3503(26, divider=1.5)   # ADC GPIO; 1.5 for the 10k/20k divider
hall.calibrate_zero()            # run with no magnet nearby
while True:
    print('B=%.0fmT' % hall.millitesla())
    time.sleep(0.5)
```
`gauss()` returns gauss. Pass `sensitivity=` (V/mT) if you calibrate against a known magnet.

## Gotchas
- **Needs 5 V:** below 4.5 V it is out of spec. Then the output can exceed 3.3 V, so always use the divider into a 3.3 V ADC pin.
- **Calibrate the zero:** the B = 0 output is 2.25–2.75 V between parts (±19 mT uncorrected). Call `calibrate_zero()`.
- **Sensitivity is typical:** 7.5–17.5 mV/mT between parts. Good for "how close / which pole", calibrate for real mT.
- **Strong neodymium magnets saturate it** when close (beyond ±90 mT it stops being linear).
- Only the field through the marked face counts; keep mechanical stress off the package.
- **ESP32 ADC:** use ADC1 pins (GPIO32–39); ADC2 stops working with Wi-Fi. The Raspberry Pi has no ADC.
- Not a switch: for on/off magnet detection use a Hall switch (A3144 / KY-003).
- A newer AH datasheet revision (AH3503/E-UA, TO-92UA, 2020) lists 15.25 mV/mT typ (12–17), 2.3–2.7 V null and ±80 mT linear; this guide follows the 4.5–6 V AH3503 sheet linked below (13.5 mV/mT typ). Either way, calibrate.
- Same part number as the discontinued Allegro A3503 / UGN3503 and the same pinout, but use the AH figures above for the AH part.
