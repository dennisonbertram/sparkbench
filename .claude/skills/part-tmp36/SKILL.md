# TMP36 analog temperature sensor (TMP36GT9Z)

## Overview
The **TMP36** (Analog Devices) is a low-voltage centigrade temperature sensor with a linear voltage output. It has no digital interface: you read the output with an ADC. Hobbyists buy the **TMP36GT9Z** in a 3-pin TO-92 package (for example Adafruit product #165, also in most Arduino starter kits).
- Scale factor: **10 mV/°C** with a **500 mV offset** (500 mV at 0 °C)
- Output: **100 mV at −40 °C**, **750 mV at 25 °C**, 1.75 V at 125 °C
- Specified **−40 °C to +125 °C**, works to 150 °C with less accuracy (5 V supply)
- Accuracy (G grade): ±1 °C typical, ±3 °C max at 25 °C; ±2 °C typical over the full range
- Supply: **2.7 V to 5.5 V**, under **50 µA**, so it runs straight from 3.3 V

## Pinout (TO-92, flat face towards you, legs down)
| Pin | Name | Function |
|-----|------|----------|
| 1 (left) | +VS | Supply, 2.7–5.5 V |
| 2 (middle) | VOUT | Analog output, 0.5 V + 10 mV/°C |
| 3 (right) | GND | Ground |

The datasheet drawing (Figure 4, T-3) is a **bottom view**: pin 1 +VS, pin 2 VOUT, pin 3 GND. The TO-92 version has no SHUTDOWN pin.

## Electrical limits
- Supply: 2.7 V min, 5.5 V max (absolute max 7 V).
- Output: GND ≤ VOUT ≤ +VS, 50 µA load max, 250 µA short-circuit limit. It never goes above 2.0 V, so it is safe for a 3.3 V ADC even at 5 V supply.
- Drives up to 1000 pF (typ 10 nF) without oscillating.

## Interface details
Conversion formula (datasheet Table 4):
```
T(°C) = (Vout(mV) − 500) / 10
```
Examples: 0.50 V = 0 °C, 0.75 V = 25 °C, 0.40 V = −10 °C, 1.0 V = 50 °C.
Put a 0.1 µF ceramic capacitor between +VS and GND close to the sensor (datasheet Figure 24).

## Wiring
| Sensor | ESP32 | Raspberry Pi Pico | Raspberry Pi 4 |
|---|---|---|---|
| +VS | 3V3 | 3V3(OUT) (pin 36) | 3.3 V (pin 1) |
| VOUT | GPIO34 (ADC1) | GP26 / ADC0 (pin 31) | External ADC input (e.g. MCP3008 CH0 or ADS1115 A0) |
| GND | GND | GND | GND |

The Raspberry Pi 4 has **no built-in ADC**, so you need an external ADC. On the ESP32 use ADC1 pins (ADC2 does not work while Wi-Fi is on).

## Using the driver
```python
from tmp36 import TMP36
import time
sensor = TMP36(26)          # GPIO number of the ADC pin VOUT is wired to
while True:
    print('T=%.1fC' % sensor.temperature())
    time.sleep(1)
```
The driver averages 32 samples. It uses calibrated `read_uv()` where the port has it (ESP32), otherwise `read_u16()` × 3.3 V / 65535 (pass `vref=` if your 3V3 rail is different).

## Gotchas
- **Pin orientation:** reversing +VS and GND makes the sensor very hot within seconds and kills it. If it is hot to the touch, unplug it.
- **Look-alikes:** the LM35 / TMP35 have no offset (0 mV at 0 °C) and the TMP37 is 20 mV/°C. Read the marking: using the wrong formula gives readings 50 °C off.
- **Resolution:** 10 mV/°C is small. A 12-bit 3.3 V ADC gives about 0.08 °C per step, and noise is bigger. Average samples and fit the 0.1 µF capacitor.
- **Pico ADC reference** is the 3.3 V rail: if it sags, readings shift. Pass the measured rail as `vref=`.
- **Placement:** the legs carry heat into the chip. Board heat, the regulator or your fingers change the reading.
