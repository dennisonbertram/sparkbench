# LMT86 analog temperature sensor (LMT86LP)

## Overview
The **LMT86** (Texas Instruments) is a precision CMOS temperature sensor with an analog voltage output. It has no digital interface: you read the output with an ADC. Hobbyists buy the **LMT86LP** in a 3-pin TO-92 package (straight leads; LMT86LPM has formed leads, same pinout).
- Output **falls** as temperature rises: average gain **−10.9 mV/°C**
- Output: **2616 mV at −50 °C**, **2100 mV at 0 °C**, **1831 mV at 25 °C**, 997 mV at 100 °C, **420 mV at 150 °C**
- Specified **−50 °C to +150 °C**
- Accuracy: ±0.4 °C typical (40–150 °C), ±0.7 °C typical (0–40 °C, VDD ≥ 2.4 V), ±2.7 °C max
- Supply: **2.2 V to 5.5 V**, only **5.4 µA**, push-pull output (±50 µA), power-on time 0.7 ms typ / 1.9 ms max

## Pinout (TO-92 LP/LPM, flat face towards you, legs down)
| Pin | Name | Function |
|-----|------|----------|
| 1 (left) | VDD | Supply, 2.2–5.5 V |
| 2 (middle) | OUT | Analog output (falls with temperature) |
| 3 (right) | GND | Ground (also the die's thermal path) |

From datasheet Figure 5-3 and Table 5-1. **The TO-92S version (LMT86LPG) has a different order: 1 OUT, 2 GND, 3 VDD.** Check the part number before wiring.

## Electrical limits
- Supply: 2.2 V min, 5.5 V max (absolute max −0.3 V to 6 V).
- Output: −0.3 V to VDD + 0.5 V absolute; ±50 µA drive. The output never exceeds 2.62 V, so it is safe for a 3.3 V ADC.
- Keep VDD − VOUT ≥ 200 mV: at −50 °C the output is 2.62 V, so a 3.3 V supply is fine (2.2 V only works down to about −5 °C).
- Capacitive load up to 1100 pF directly; larger capacitors need a series resistor (3 kΩ for 1.1–99 nF, 1.5 kΩ for 100–999 nF, 800 Ω for 1 µF).

## Interface details
The response is very linear but slightly parabolic. The reference is the datasheet **Transfer Table (Table 7-1)**, one mV value for every degree from −50 to 150 °C; the driver interpolates it.
The datasheet's parabolic approximation (Equation 1, off by up to 10 mV at the extremes):
```
VOUT(mV) = 1777.3 − 10.888 × (T − 30) − 0.00347 × (T − 30)²
```
Examples from Table 7-1: 2.100 V = 0 °C, 1.831 V = 25 °C, 1.668 V = 40 °C, 1.558 V = 50 °C, 0.997 V = 100 °C.
For a quick linear estimate over 20–50 °C the datasheet gives V(mV) = −10.9 × T + 2103.

## Wiring
| Sensor | ESP32 | Raspberry Pi Pico | Raspberry Pi 4 |
|---|---|---|---|
| VDD | 3V3 | 3V3(OUT) (pin 36) | 3.3 V (pin 1) |
| OUT | GPIO34 (ADC1) | GP26 / ADC0 (pin 31) | External ADC input (e.g. MCP3008 CH0 or ADS1115 A0) |
| GND | GND | GND | GND |

The Raspberry Pi 4 has **no built-in ADC**, so you need an external ADC. On the ESP32 use ADC1 pins (ADC2 does not work while Wi-Fi is on). Add a 0.1 µF bypass capacitor across VDD/GND and, for a sampling ADC, a small filter capacitor (≤ 1.1 nF without series resistor) on OUT (datasheet Figure 8-1).

## Using the driver
```python
from lmt86 import LMT86
import time
sensor = LMT86(26)          # GPIO number of the ADC pin OUT is wired to
while True:
    print('T=%.1fC' % sensor.temperature())
    time.sleep(1)
```
The driver averages 32 samples. It uses calibrated `read_uv()` where the port has it (ESP32), otherwise `read_u16()` × 3.3 V / 65535 (pass `vref=` if your 3V3 rail is different). `mv_to_celsius(mv)` converts a voltage you measured some other way (e.g. with an ADS1115).

## Gotchas
- **The output goes DOWN when it gets warmer.** Formulas for LM35/TMP36 give nonsense here.
- **Pin order differs between packages:** TO-92 (LP/LPM) is VDD-OUT-GND, TO-92S (LPG) is OUT-GND-VDD.
- **Low power:** at 5.4 µA you can power it from a GPIO and switch it off between readings; wait 2 ms after power-on before reading.
- **Resolution:** about 11 mV/°C. A 12-bit 3.3 V ADC gives about 0.07 °C per step. Average samples.
- **Pico ADC reference** is the 3.3 V rail: if it sags, readings shift. Pass the measured rail as `vref=`.
- **Placement:** the GND leg is tied to the die, so board heat flows straight into the reading. Keep it away from the regulator and MCU.
