# TMP36 analog temperature sensor (TMP36GT9Z)

## Overview
The **TMP36** (Analog Devices, part of the TMP35/TMP36/TMP37 family) is a low-voltage centigrade temperature sensor with a linear voltage output. It has no digital interface: you read the output with an ADC.
- Scale factor: **10 mV/°C**
- Output: **750 mV at 25 °C**, with a 500 mV offset so it can read below 0 °C
- Range: **−40 °C to +125 °C**
- Accuracy: typically ±1 °C at 25 °C and ±2 °C over −40 to +125 °C
- Supply: **2.7 V to 5.5 V**, quiescent current **< 50 µA**

## Pinout (TO-92, flat face towards you, legs down)
| Pin | Name | Function |
|-----|------|----------|
| 1 (left) | +Vs | Supply, 2.7–5.5 V |
| 2 (middle) | VOUT | Analog output |
| 3 (right) | GND | Ground |

The SOIC-8 and SOT-23-5 versions also have an active-low SHUTDOWN pin, which cuts the current to under 0.5 µA. The TO-92 version does not have this pin.

## Electrical limits
- Supply: 2.7 V min, 5.5 V max (absolute max 7 V)
- Output range: about 0.1 V (−40 °C) to 1.75 V (+125 °C)
- Operating range: −40 °C to +125 °C (storage −65 °C to +160 °C)
- Self-heating in still air is small because the sensor draws so little current

## Interface details
Conversion formula:
```
T(°C) = (Vout − 0.5) × 100
```
Examples: 0.5 V = 0 °C, 0.75 V = 25 °C, 1.0 V = 50 °C.
The output can drive up to about 10 nF directly. For longer cables or higher capacitance, add about 750 Ω in series or an RC filter. Put a 0.1 µF bypass capacitor across the supply pins.

## Wiring
| Sensor | ESP32 | Raspberry Pi Pico | Raspberry Pi 4 |
|---|---|---|---|
| +Vs | 3V3 | 3V3(OUT) (pin 36) | 3V3 (pin 1) via the ADC module |
| VOUT | GPIO34 (ADC1) | GP26 / ADC0 (pin 31) | External ADC input (e.g. ADS1115 A0 or MCP3008 CH0) |
| GND | GND | GND (or AGND pin 33) | GND |

The Raspberry Pi 4 has **no built-in ADC**, so you need an external ADC such as an ADS1115 (I2C) or MCP3008 (SPI). On the ESP32, use ADC1 pins (GPIO32–39), because ADC2 stops working while Wi-Fi is on.

## Using it (MicroPython)
No driver is needed. Just read the ADC.

**Raspberry Pi Pico:**
```python
from machine import ADC
import time

adc = ADC(26)  # GP26 = ADC0

def read_c(samples=16):
    total = 0
    for _ in range(samples):
        total += adc.read_u16()
    v = (total / samples) * 3.3 / 65535
    return (v - 0.5) * 100

while True:
    print("%.1f C" % read_c())
    time.sleep(1)
```

**ESP32:**
```python
from machine import ADC, Pin
adc = ADC(Pin(34))
adc.atten(ADC.ATTN_11DB)
v = adc.read_uv() / 1_000_000  # calibrated microvolts (recent MicroPython)
print((v - 0.5) * 100, "C")
```

## Gotchas
- **Pin orientation:** the pinout is shown with the *flat* face towards you. Reversing +Vs and GND makes the part very hot.
- **Look-alikes:** LM35 (10 mV/°C, no offset, needs at least 4 V) and TMP37 (20 mV/°C) use different formulas, so check the part marking.
- **ADC reference:** the formula assumes the ADC reference really is 3.3 V. Measure your 3V3 rail, or use a calibrated read (ESP32 `read_uv`).
- **Noise:** jumpy readings are normal with a 12-bit ADC (about 0.08 °C per LSB on the Pico, but noise is larger). Average the samples and add the 0.1 µF bypass capacitor.
- **Placement:** heat from the board, regulator or your fingers gets into the leads and changes the reading.
