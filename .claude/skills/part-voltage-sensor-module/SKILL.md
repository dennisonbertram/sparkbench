# Voltage sensor module (0-25 V, 5:1 divider)

## Overview
The common **"Voltage Sensor Module DC 0-25V"** (small blue PCB sold under many names, e.g. "Voltage Detection Sensor Module 25V") contains no chip: just a **resistive divider**, R1 = **30 kΩ** from the input to S and R2 = **7.5 kΩ** from S to ground.
- V(S) = Vin × 7.5 / (30 + 7.5) = **Vin / 5**
- Vin = **5 × V(S)**
- "0-25 V" assumes a 5 V ADC (Arduino Uno). On a 3.3 V board the limit is 5 × the ADC full scale: about **16.5 V** (Pico) or **15.5 V** (ESP32, 11 dB).

## Pinout
Input side (2-way screw terminal, the voltage being measured):
| Terminal | Function |
|---|---|
| VCC | + of the measured DC source (0-25 V) |
| GND | − of the measured source |

Output side (3-pin header, modelled in Sparkbench, in order):
| Pin | Name | Function |
|---|---|---|
| 1 | S | Analog output = Vin / 5 → MCU ADC pin |
| 2 | + | Not connected |
| 3 | - | Ground → MCU GND (same net as terminal GND) |

Source: Components101 and Microcontrollerslab pin tables (VCC, GND, S, +, -; "+" not connected).

## Electrical limits
- No supply needed: the module is passive. Do not connect "+" to anything that matters; it goes nowhere.
- Input: 0-25 V DC with a 5 V ADC; keep V(S) below your ADC's maximum (3.3 V boards: Vin ≤ ~16 V).
- Load on the measured source: Vin / 37.5 kΩ (0.32 mA at 12 V).
- DC only, and polarity matters: a reversed source drives S negative.

## Interface details
```
V(S) = Vin × R2 / (R1 + R2) = Vin / 5        (R1 = 30 kΩ, R2 = 7.5 kΩ)
Vin  = 5 × V(S)
```
Examples: 3.7 V → 0.74 V, 12 V → 2.4 V, 15 V → 3.0 V.
Resistor tolerance (typically 1 %) gives about ±2 % error; calibrate the ratio against a multimeter for better accuracy.

## Wiring
| Module | ESP32 | Raspberry Pi Pico | Raspberry Pi 4 |
|---|---|---|---|
| S | GPIO34 (ADC1) | GP26 / ADC0 | ADS1115 A0 (the Pi has no ADC) |
| + | not connected | not connected | not connected |
| - | GND | GND | GND |
| VCC / GND terminals | source being measured (+ / −) | same | same |

## Using the driver
```python
from voltsense import VoltageSensor
import time
vs = VoltageSensor(26)        # GPIO number of the ADC pin S is wired to
while True:
    print('V=%.1f' % vs.volts())
    time.sleep(0.5)
```
`sense_volts()` returns V(S). Pass `r1=`/`r2=` for other divider values, `vref=` if the ADC reference is not 3.3 V (ports without `read_uv()`).

## Gotchas
- **Over-range on 3.3 V boards:** 20 V in puts 4 V on S, above the ESP32/Pico ADC limit. Stay under ~15 V or use a bigger divider.
- **Common ground:** the "-" pin and the terminal GND are the same net, so the measured source's negative becomes your MCU's ground. Never measure a source whose negative isn't allowed to be at MCU ground (e.g. high-side of a bridge, mains).
- **ESP32 ADC:** non-linear near 0 V and above ~2.5 V; use ADC1 pins (ADC2 fails with Wi-Fi on). `read_uv()` is calibrated and preferred.
- **High source impedance (6 kΩ at S):** fine for ESP32/Pico, but averaging several samples reduces noise.


## On a 3.3 V board
- **S** can rise above 3.3 V, so on an ESP32 or Pico it goes to the GPIO through a divider: 10 kΩ from S to the pin, 20 kΩ from the pin to GND (Sparkbench adds both resistors). The pin then sees 0.67 × the output voltage, so multiply ADC readings by 1.5 (the driver's `divider` / `div` argument does this).
