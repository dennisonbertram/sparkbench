## How popularity was measured

- **★ (CP / Ard)**: GitHub stars of the `adafruit/Adafruit_CircuitPython_<X>` and `adafruit/Adafruit_<X>` Arduino repos, fetched through the GitHub API on 2026-10-22. The CircuitPython Bundle has 1008★, SSD1306 325★ and NeoPixel 330★, for scale.
- **G(py/ino)**: how many project folders in `adafruit/Adafruit_Learning_System_Guides` import the driver (`import adafruit_x` or `#include <Adafruit_X.h>`). The code repo was sparse-cloned and grepped. This is a proxy for how many Learn guides use the product.
- **Cat#**: the product's position in the default listing of an Adafruit category page, fetched 2026-10-22. The order is not documented. It looks popularity- or featured-weighted (for example the BNO085 is #1 in Sensors), so treat it as a weak signal. The codes are: S = Sensors (35), BB = Breakout Boards (42), QT = STEMMA QT Devices (620), D = LCDs & Displays (63), R = Robotics (227), ST = STEMMA (1005), C = Components (54), W = Wireless (112), L = LEDs (37).
- **Status**: every product ID below is active (not discontinued) in `adafruit.com/api/products` as of 2026-10-22. Popular products that are discontinued were left out, for example the TCS34725 (#1334), VEML6075, CCS811, SI1145 and TSL2561.
- **Power and logic** facts marked ✓ were read off the live product page. The others come from Adafruit's usual board design: most STEMMA QT boards take 3–5 V, have a 3.3 V regulator and are safe on the I2C lines. Check those against the product page before a part is made.
- **MicroPython (MP)**: "community" means a third-party MicroPython driver is known to exist. "trivial" means a few register writes are enough, so the part's own `.py` driver is straightforward.

## Caveats

- The CircuitPython star count for #2448 TB6612 (adafruit_motor, G 77) counts every motor guide, not this board alone. The ST7789 / ILI9341 / SSD1306 star counts are likewise shared across sizes.
- Learn-guide counts come from the code repo. Guides without code, and products used through a generic library (for example `board`/`analogio` for analog parts), are under-counted. That is why analog and passive parts show 0.
- The Adafruit category order is a weak, undocumented popularity signal. There is no public best-seller list, and the category pages offer no sort parameter.
- **Not verified on product pages**: I2C addresses for the newest 2025–26 boards (the TCS3430 / TCS3448, TMF88xx, GP8403, ADS7128, AS7331 and APDS9999 rows). Check them during the part-check datasheet reading.
